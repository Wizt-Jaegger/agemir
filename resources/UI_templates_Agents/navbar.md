# Navbar (top navigation bar)
Guideline, not code to copy. Adapt it to the project's framework and keep its structure.

Layout
- One horizontal bar, full width, fixed height of 56-64 px, stays at the top (sticky).
- Left: logo or app name. Centre or right: 3-6 links. Far right: one primary action (login, profile icon).
- Content is vertically centred. Spacing between items: 16-24 px. Side padding: 16-24 px.

Look
- Flat background that contrasts with the page, a 1 px bottom border or a soft shadow, not both.
- One accent colour, used only for the active link and the primary action.
- Active link: accent colour plus a 2 px underline. Hover: slightly lighter background, 150 ms transition.

Behaviour
- Highlight the current page. Links are real links, reachable with Tab, with a visible focus outline.
- Below 768 px wide, hide the links and show the hamburger menu (see hamburger-menu.md).

Avoid: more than 6 links, text under 14 px, several accent colours, icons without a label or title.
